# Metro browser example

This example starts a Metro Live router over HTTP, then drives its page with
Shakespeare. The Slick browser spec covers a larger registration and chat
journey with a persisted message.

From the Shakespeare checkout, with Metro and Harmat beside it:

```sh
kex --source-root src --source-root ../metro/src --source-root ../harmat/src examples/metro/spec/home.spec.kex
```
